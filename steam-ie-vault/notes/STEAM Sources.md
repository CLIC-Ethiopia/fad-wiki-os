# 3. STEAM-Active Project ⭐⭐⭐⭐⭐

**Website**

[STEAM-Active Protocol](https://epale.ec.europa.eu/en/resource-centre/content/steam-active-teachers-protocol?utm_source=chatgpt.com)

This may be the single best **methodology website** available.

It contains a complete protocol for

- defining STEAM
- interdisciplinary learning
- transdisciplinary learning
- project-based learning
- curriculum design
- lesson design
- assessment
- evaluation

The documentation is nearly a handbook.

Instead of saying

> "STEAM is Science Technology Engineering Arts Mathematics"

it explains

- WHY
- HOW
- WHEN
- WHAT
- assessment methods
- learning sequence design

It also includes

- Circular Economy
- Gender
- Sustainability

within STEAM curriculum design. [EPALE](https://epale.ec.europa.eu/en/resource-centre/content/steam-active-teachers-protocol?utm_source=chatgpt.com)
