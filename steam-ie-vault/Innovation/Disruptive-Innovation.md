# Disruptive Innovation

#Innovation #STEAM-IE #Disruption

Disruptive innovation is an innovation that creates a new market and value network and eventually disrupts an existing market and value network, displacing established market-leading firms, products, and alliances. Closely linked to [[Lean-Startup]].
