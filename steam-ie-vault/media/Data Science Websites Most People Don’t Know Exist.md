If you're learning data science, you don't always need another course or another 20-hour tutorial.  
  
There are some really useful websites that can help you find datasets, understand statistics, learn machine learning, and even see how other people build data visualizations.  
  
In this video, I go through some of the data science websites I think are actually worth knowing.  
  
You'll see:-  
  
• Google Dataset Search for finding datasets from different sources  
• UCI Machine Learning Repository for ready-to-use machine learning datasets  
• Data Is Plural for finding unusual and interesting datasets  
• Seeing Theory for learning probability and statistics visually  
• R2D3 for understanding machine learning without starting with complicated code  
• Setosa.io for interactive explanations of statistics and machine learning  
• Distill for clear visual explanations of machine learning research  
• OpenIntro for free statistics textbooks, exercises, and resources  
• Tableau Public for exploring real-world dashboards and data visualizations  
  
Whether you're just getting into data science, learning machine learning, working with datasets, or simply curious about how data works, these websites are worth checking out.  
  
Some of them can save you hours of searching. Others make concepts that normally feel complicated much easier to understand.  
  
And the best part is that many of these resources are completely free.
