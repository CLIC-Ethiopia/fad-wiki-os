# Bioinformatics

#Interdisciplinary #STEAM-IE #Bioinformatics

Bioinformatics is an interdisciplinary field that develops methods and software tools for understanding biological data, in particular when the data sets are large and complex. It links [[Biology]], [[Data-Science]], and [[Applied-Statistics]].
